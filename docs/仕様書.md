## 1. 概要

### 1.1 目的

ユーザーの Web カメラ映像から骨格（ポーズ）を推定し、選択したヨガポーズの関節角度が目標値にどれだけ近いかをリアルタイムで採点する。

### 1.2 対象ユーザー

- 自宅でヨガのフォームを確認したい初心者〜中級者
- インストラクター補助として姿勢の目安を知りたい利用者

### 1.3 スコープ

| 含む | 含まない |
|------|----------|
| ブラウザ内カメラ撮影 | サーバー側での映像保存・解析 |
| 3 種類のポーズ採点 | 医療・診断用途の精度保証 |
| リアルタイムスコア表示 | ユーザーアカウント・履歴 DB |
| Vercel への静的ホスティング | 動画の録画・再生 |

## 2. 機能要件

### 2.1 画面構成

| 領域 | 内容 |
|------|------|
| ヘッダー | タイトル、説明文 |
| ポーズ選択 | ドロップダウン、ポーズの短い説明 |
| メイン左 | カメラ映像 + 骨格オーバーレイ |
| メイン右 | 総合スコア、評価ラベル、項目別スコア・フィードバック |
| フッター | 利用上の注意、エラー表示 |

### 2.2 ポーズ一覧

| ID | 表示名 | 採点項目数 |
|----|--------|------------|
| `tree` | 木のポーズ | 2 |
| `warrior2` | 戦士のポーズ2 | 3 |
| `downward_dog` | 下向きの犬 | 3 |

左右の足・腕はポーズ定義で固定（例: 木のポーズは左が軸足）。反対側で行う場合の自動切り替えは未実装。

### 2.3 カメラ

- `getUserMedia` により前面カメラ（`facingMode: 'user'`）を使用
- 解像度目標: 1280×720（端末が対応する範囲）
- 映像はミラー表示（左右反転）でユーザーが鏡のように確認できる
- 「カメラを開始」「カメラを停止」で制御

### 2.4 ポーズ検出

- **エンジン**: Google MediaPipe Pose Landmarker（`@mediapipe/tasks-vision`）
- **モデル**: `pose_landmarker_lite`（float16）
- **実行モード**: `VIDEO`（フレームごと `detectForVideo`）
- **検出人数**: 1 人
- **処理場所**: クライアント（ブラウザ）のみ。映像はサーバーに送信しない

初回起動時、WASM とモデルファイルを CDN からダウンロードする（数 MB、回線次第で数十秒）。

### 2.5 採点ロジック

#### 2.5.1 関節角度

3 点（a — b — c）のうち、頂点 b における角度（0〜180°）を計算する。

各ランドマークの `visibility` が 0.5 未満の場合はその項目を未検出とする。

#### 2.5.2 項目スコア

```
diff = |測定角度 − 目標角度|
項目スコア = max(0, min(100, 100 − (diff / tolerance) × 100))
```

- `target`: 目標角度（度）
- `tolerance`: 満点から 0 点になるまでの許容幅（度）
- `weight`: 総合スコアへの重み

#### 2.5.3 総合スコア

検出できた項目のみを対象に、重み付き平均を四捨五入した 0〜100 点。

1 項目も検出できない場合は `detected: false` とし、総合は「—」表示。

#### 2.5.4 評価ラベル（総合）

| 総合スコア | ラベル |
|------------|--------|
| 85 以上 | 素晴らしい |
| 70 以上 | 良い |
| 50 以上 | もう一息 |
| 50 未満 | 調整しましょう |

#### 2.5.5 フィードバック文言（項目別）

| 条件 | 文言 |
|------|------|
| \|diff\| ≤ tolerance × 0.35 | とても良いです |
| \|diff\| ≤ tolerance | もう少し調整してみてください |
| 測定 > 目標 | 角度を少し小さく |
| 測定 < 目標 | 角度を少し大きく |
| 未検出 | 全身がカメラに入るように立ってください |

### 2.6 採点項目詳細

#### 木のポーズ（`tree`）

| 項目 ID | ラベル | 目標 | 許容 | 重み |
|---------|--------|------|------|------|
| standing_leg | 軸足（左）の伸展 | 175° | 18° | 1.0 |
| lifted_knee | 上げた足（右）の膝 | 55° | 28° | 1.1 |

#### 戦士のポーズ2（`warrior2`）

## 3. 非機能要件

### 3.1 対応ブラウザ

- Chrome / Edge / Safari / Firefox の最新版を想定
- **HTTPS 必須**（本番: Vercel）。`localhost` は開発時のみ HTTP 可
- カメラ API と WebAssembly に対応した環境が必要

### 3.2 パフォーマンス

- 採点は `requestAnimationFrame` ループ内で動画フレーム更新時のみ実行
- GPU デリゲートを優先し、失敗時は CPU にフォールバック

### 3.3 プライバシー

- 映像・骨格データは端末内で処理し、外部 API へ映像を送信しない
- MediaPipe のモデル・WASM は Google CDN / jsDelivr から取得

### 3.4 制限・免責

- 採点は**目安**であり、正確なヨガ指導・医学的評価を代替しない
- 照明・服装・カメラ距離・遮蔽により精度が大きく変動する

## 4. 技術構成

### 4.1 スタック

| 層 | 技術 |
|----|------|
| UI | React 19 + TypeScript |
| ビルド | Vite 8 |
| ポーズ推定 | @mediapipe/tasks-vision 0.10.x |
| ホスティング | Vercel（静的サイト、`dist`） |

### 4.2 ディレクトリ構成（主要）

```
src/
  App.tsx                 # 画面全体
  components/
    PoseCamera.tsx        # カメラ・描画・検出ループ
  hooks/
    usePoseLandmarker.ts  # MediaPipe 初期化
  lib/
    landmarks.ts          # ランドマーク index
    geometry.ts           # 角度・可視性
    poses.ts              # ポーズ定義
    scoring.ts            # 採点
vercel.json               # SPA リライト
```

### 4.3 外部依存 URL

| 用途 | URL |
|------|-----|
| WASM | `https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision/wasm` |
| モデル | `https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task` |

### 4.4 ビルド・デプロイ

```bash
npm run build    # tsc + vite build → dist/
vercel --prod    # 本番デプロイ
```

`vercel.json` で全パスを `index.html` にリライト（SPA）。
