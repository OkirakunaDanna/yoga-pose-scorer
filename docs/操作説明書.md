# ヨガポーズ採点 Web アプリ — 操作説明書

**対象**: 利用者（インストラクター・自習者）  
**URL**: https://yoga-pose-scorer.vercel.app  
**印刷用 PDF**: [docs/latex/操作説明書.pdf](./latex/操作説明書.pdf)（LuaLaTeX）

---

## 1. このアプリでできること

- スマホや PC のカメラで、ヨガのポーズを**リアルタイム**で採点します
- **3 種類**のポーズに対応しています（木のポーズ / 戦士のポーズ2 / 下向きの犬）
- 映像は**あなたの端末の中だけ**で処理されます（サーバーに送りません）

採点はあくまで**目安**です。体調に合わせ、無理のない範囲でご利用ください。

---

## 2. 動作環境

| 項目 | 要件 |
|------|------|
| ブラウザ | Chrome、Safari、Edge、Firefox など最新版 |
| 接続 | インターネット（初回のみ AI モデルのダウンロード） |
| カメラ | 内蔵または外付け Web カメラ |
| HTTPS | 本番サイトは HTTPS のためカメラ利用可 |

**注意**: `http://` の一般サイトではカメラが使えないことがあります。本番 URL（`https://yoga-pose-scorer.vercel.app`）をご利用ください。

## 4. 基本的な使い方

### ステップ 1 — サイトを開く

ブラウザで次の URL を開きます。

**https://yoga-pose-scorer.vercel.app**

### ステップ 2 — ポーズを選ぶ

「**練習するポーズ**」のプルダウンから、練習したいポーズを選びます。

![ポーズ選択画面](./screenshots/01_初期表示.png)

| ポーズ名 | ざっくりした形 |
|----------|----------------|
| 木のポーズ | 片足で立ち、もう一方の足を内ももに |
| 戦士のポーズ2 | 前足の膝を曲げ、腕を左右に伸ばす |
| 下向きの犬 | 手と足で床を押し、お尻を上げた逆 V 字 |

選ぶと、その下に短い説明が表示されます。

### ステップ 3 — カメラを開始する

1. **「カメラを開始」** をタップ／クリックします  
2. ブラウザから **カメラの使用を許可** してください  
3. 初回のみ **「モデル読み込み中…」** と表示されることがあります（数十秒かかる場合あり）

許可を拒否した場合は、ブラウザの設定からこのサイトのカメラを許可し、ページを再読み込みしてください。

### ステップ 4 — ポーズをとる

- カメラから **2〜3 m 程度** 離れ、**頭から足まで** が画面に入るようにします  
- 明るい場所で、体のラインが隠れない服装がおすすめです  
- 画面は鏡のように左右反転して表示されます（自分が見慣れた向き）

骨格の線（緑）が体に沿って表示されれば、検出できています。

### ステップ 5 — スコアを確認する

**右側のパネル**（スマホでは下）を見ます。

| 表示 | 意味 |
|------|------|
| **大きい数字 + 「点」** | 総合スコア（0〜100） |
| **その下の短い文** | 総合評価（例: 素晴らしい / 良い） |
| **リストの各項目** | 部位ごとの点数 |
| **「現在 ○° / 目標 ○° — …」** | 今の角度とアドバイス |

総合スコアが **「—」** のまま、「全身を映してください」と出る場合は、もう少し離れるか、カメラの向きを調整してください。

### ステップ 6 — 終了する

**「カメラを停止」** でカメラをオフにできます。ブラウザのタブを閉じてもカメラは停止します。

## 5. スコア・フィードバックの読み方

### 5.1 総合スコアの目安

| 点数 | 表示される評価 |
|------|----------------|
| 85 点以上 | 素晴らしい |
| 70 点以上 | 良い |
| 50 点以上 | もう一息 |
| 50 点未満 | 調整しましょう |

### 5.2 項目ごとの表示例

```
軸足（左）の伸展          85点
現在 172° / 目標 175° — とても良いです
```

| 部分 | 説明 |
|------|------|
| 現在 ○° | カメラが検出した今の角度 |
| 目標 ○° | このポーズで近づけたい角度 |
| 最後の文 | 調整のヒント |

よく出るヒント:

| ヒント | 意味 |
|--------|------|
| とても良いです | 目標にかなり近い |
| もう少し調整してみてください | あと少し |
| 角度を少し大きく / 小さく | 関節をもう少し曲げる／伸ばすイメージ |

### 5.3 左右について

現在のバージョンでは、**左足・右足がポーズごとに固定**されています（例: 木のポーズは「左が軸足」想定）。反対の足で行うと、項目名と実際の足が一致しないことがあります。その場合も角度の数値は参考にできます。

## 6. うまくいかないとき

| 症状 | 対処 |
|------|------|
| カメラが真っ暗 | 許可ダイアログで「許可」／設定 → プライバシー → カメラ |
| ずっと「モデル読み込み中」 | 回線を確認し、再読み込み（F5） |
| スコアが「—」のまま | 全身が入るよう距離・明るさを調整 |
| 骨格線が乱れる | 逆光を避ける、余計な物が体に重ならないようにする |
| 点数が急に上下する | 正常です。姿勢をキープすると安定します |
| 初回だけ遅い | AI モデルのダウンロード。2 回目以降は速くなります |

---

## 7. プライバシーについて

- カメラ映像は**あなたのブラウザ内**で処理されます  
- 当アプリのサーバーに**映像や録画を保存しません**  
- 初回に Google / jsDelivr 経由で AI モデルファイルを取得します
